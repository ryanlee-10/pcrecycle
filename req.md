i want to build a PC recycle website of modern ui, modern features, for recycling PC parts, the website is for my own personal use, so i don't need any login system, just a simple form to submit PC parts and a simple database to store them, the website should be responsive and easy to use, it should also be fast and efficient, it should be built with modern technologies, i prefer to use nextjs, tailwindcss, and shadcn/ui.

## features:
- home page
    - search bar
    - featured items
    - categories
- item page
    - item details
    - add to cart
    - checkout
- checkout page
    - shipping information
    - payment information
    - order summary
- contact page
    - contact form
    - contact information
- terms and conditions page
    - terms and conditions
- privacy policy page
    - privacy policy

## features:
- corporate customers can donate their old PC parts to the website
- the website should then sell the parts and give the profits to charity
- the website should also have a system to track the donations and the profits
- **A dashboard for corporate users**: to show their donation history and the profits from their donations
- **A dashboard for admin**: to manage the website, users, donations, and profits
